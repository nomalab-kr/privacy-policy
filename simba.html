개인정보처리방침

서비스 이름: 심바 (Simba)
형태: Windows 데스크톱 프로그램(설치형)
운영: 엉클노마(노마랩) · 문의 cap.wtkim@gmail.com
시행일: 2026-07-24

심바(이하 "서비스")는 사용자가 본인의 YouTube Data API 키를 입력해 유튜브 키워드·채널·영상을 검색하고 성과를 분석하는 도구입니다. 본 방침은 서비스가 어떤 정보를 처리하고, 어떻게 보관하며, 누구와 공유하는지 설명합니다.

핵심 요약
검색·분석에 쓰는 YouTube·Gemini API 키와 검색기록·북마크·분석 결과는 사용자 PC 안에만 저장되며 서버로 전송되지 않습니다. 서버에는 로그인용 카카오 계정 이메일, 구독·이용권 상태, 기기 구분용 식별자 해시와 유료 결제 신청 정보만 저장합니다. 이름·전화번호·위치·하드웨어 고유정보는 수집하지 않습니다.

1. 서버에 저장·처리하는 정보

정보용도보관
카카오 계정 이메일
(카카오 로그인 시 제공)		 회원 식별, 로그인, 구독·이용권 연결 노마랩 인증 서버(Supabase)에 저장
구독·이용권 상태
(요금제·만료일·부여 이력)		 유료 이용권 확인, 무료 사용 한도 관리, 만료·갱신 안내 서버에 저장
기기 식별자 해시
(앱이 생성한 임의 식별값의 해시)		 유료 이용권의 1인 1PC 정책 확인(다른 PC 사용 차단·기기 해제) 서버에 해시값만 저장. 원본 식별자·하드웨어 정보는 저장하지 않음
무료 사용 횟수
(날짜·동작 단위 카운트)		 무료 이용자의 일일 사용 한도 계산 서버에 저장
결제 신청 정보
(입금자명·이메일·기간·금액)		 무통장 입금 구매 신청 접수 및 입금 확인·이용권 부여 서버에 저장(분쟁·환불 근거). 카드번호 등 결제수단 정보는 수집하지 않음
서비스 이용 통계
(Google Analytics)		 접속·이용 현황 분석(개별 신원과 연결하지 않는 집계) Google Analytics가 정책에 따라 처리

본 서비스는 사용자의 이름, 전화번호, 정확한 위치, 연락처, 사진 등 민감·신원 정보와 CPU·디스크 일련번호 같은 하드웨어 고유정보를 수집하지 않습니다.

2. 사용자 PC에만 저장되는 정보(서버 미전송)

  • YouTube Data API 키 · Gemini API 키: 사용자가 직접 발급해 입력한 키로, Windows 자격 증명 관리자에 안전하게 보관됩니다. 노마랩 서버로 전송·저장되지 않습니다.
  • 검색기록 · 북마크 · 캐시 · 분석 결과: 사용자 PC의 로컬 데이터베이스에만 저장됩니다.

다음 요청은 사용자 PC에서 사용자 본인의 API 키로 직접 이루어지며, 노마랩 서버를 거치지 않습니다.

5. 결제·구독에 관하여

유료 구독은 무통장 입금 방식으로 신청·이용권이 부여됩니다. 이용권은 만료일까지 유효하며, 만료 시 무료 이용 한도로 전환됩니다. 해지 방법·자동갱신 여부·환불 규정 등 거래 조건은 구매 페이지 및 이용약관에 별도로 고지됩니다.

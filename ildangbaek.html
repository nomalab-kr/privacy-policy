일당백 플러그인(이하 "확장")은 네이버에서 검색할 때 연관 키워드의 월간 검색량을 검색 결과 위에 표시하고, 웹페이지의 드래그·우클릭 방지를 해제(드래그프리)하는 도구입니다. 본 방침은 확장이 어떤 정보를 다루고, 어디에 보관하며, 어디로 보내는지 설명합니다.

핵심 요약
확장은 운영자 서버가 없으며, 사용자 데이터를 운영자에게 전송하지 않습니다. 사용자가 직접 입력한 네이버 검색광고 API 정보(API Key·Secret·Customer ID)와 설정, 최근 검색량 캐시는 사용자 브라우저 안의 확장 저장소에만 저장됩니다. 검색량을 가져오기 위해 검색어가 네이버 검색광고 API로만 전송됩니다. 드래그프리 기능은 페이지 안에서만 동작하며 어떤 내용도 읽거나 전송하지 않습니다.

1. 확장이 다루는 정보

정보용도보관 위치
네이버 검색광고 API 정보
(API Key·API Secret·Customer ID)		 사용자를 대신해 네이버 검색광고 API에 키워드 검색량을 요청 사용자 브라우저의 확장 저장소(storage.local)에만 저장. 운영자에게 전송되지 않음. 사용자가 팝업에서 언제든 수정·삭제 가능
네이버에서 입력한 검색어 연관 키워드와 월간 검색량 조회 저장하지 않음. 네이버 검색광고 API 요청에만 사용
키워드 검색량 캐시 같은 검색어를 5분 안에 다시 검색할 때 빠르게 표시 확장 저장소에 임시 보관. 5분 후 만료되며 팝업에서 즉시 삭제 가능
기능 설정
(검색량 표시·드래그프리 켬/끔 등)		 사용자가 고른 기능 상태 유지 확장 저장소에만 저장
라이선스 키 이용 자격 확인 확장 안에서만 확인하며 외부로 전송하지 않음

확장은 이름, 이메일, 전화번호, 위치, 방문 기록, 페이지 내용, 로그인 정보, 결제 정보 등 어떤 개인정보도 수집하지 않으며, 이용 통계나 분석 도구도 사용하지 않습니다.

2. 권한별 사용 목적

  • search.naver.com 접근: 네이버 검색 결과 페이지에 검색량 표를 표시하고 검색어를 강조하기 위해 사용합니다.
  • api.searchad.naver.com / api.naver.com 접근: 사용자의 API 정보로 네이버 검색광고 API에 검색량을 요청하기 위해 사용합니다.
  • 모든 사이트(<all_urls>) 접근: 드래그·우클릭·복사 방지를 해제하는 드래그프리 기능을 어떤 사이트에서든 쓸 수 있게 하기 위해 사용합니다. 이 기능은 페이지의 이벤트 제한만 풀 뿐, 페이지 내용을 읽거나 저장·전송하지 않습니다.
  • storage: API 정보, 설정, 검색량 캐시를 브라우저 안에 저장합니다.
  • activeTab: 아이콘 클릭 또는 단축키(Alt+1)로 현재 탭에서만 드래그프리를 켜고 끄기 위해 사용합니다.

3. 외부 서비스로의 요청

  • 네이버 검색광고 API: 사용자가 네이버에서 검색할 때, 사용자 본인의 API 정보로 검색어의 연관 키워드 검색량을 요청합니다. 요청에는 검색어와 API 인증 정보만 포함됩니다. — 네이버 검색광고 API 안내

그 밖의 어떤 서버로도 데이터를 보내지 않습니다. 운영자는 사용자의 API 정보나 검색어를 볼 수 없습니다.

4. 제3자 제공 / 처리위탁

확장은 사용자 데이터를 제3자에게 판매·제공하거나 처리위탁하지 않습니다. 위 3항의 네이버 API 요청은 사용자가 직접 발급받은 API 계정으로 사용자를 대신해 이루어지며, 네이버의 개인정보 처리는 네이버 개인정보처리방침을 따릅니다.

5. 데이터 보관 및 삭제

모든 데이터는 사용자 브라우저 안에만 있습니다. 확장 팝업에서 API 정보를 지우거나 캐시 삭제 버튼을 누르면 즉시 삭제되며, 확장을 제거하면 저장된 모든 데이터가 함께 삭제됩니다. 운영자가 보관하는 사용자 데이터는 없으므로 별도의 삭제 요청 절차가 필요하지 않습니다.

6. 안전성 확보 조치

  • API 정보는 브라우저 동기화(sync)가 아닌 로컬 확장 저장소에만 두어 다른 기기로 전송되지 않게 합니다.
  • 네이버 API와의 통신은 HTTPS로만 이루어집니다.
  • 확장은 사용자 식별자를 만들거나 수집하지 않습니다.

7. 만 14세 미만 아동의 개인정보

확장은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

8. 변경 사항

본 방침이 변경되면 본 페이지에서 갱신된 내용을 확인할 수 있습니다. 데이터 처리 방식이 바뀌는 중요한 변경은 확장 업데이트 안내와 함께 알립니다.

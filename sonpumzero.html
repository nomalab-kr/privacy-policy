손품제로(이하 "서비스")는 사용자가 본인의 쿠팡 파트너스 Open API 키를 등록해 두고, 쿠팡 상품 페이지에서 버튼을 눌러 파트너스 링크를 만들어 복사·보관하는 도구입니다. 본 방침은 서비스가 어떤 정보를 처리하고, 어떻게 보관하며, 누구와 공유하는지 설명합니다.

핵심 요약
링크 생성은 노마랩 서버가 사용자의 쿠팡 API 키로 대신 호출합니다. 그래서 쿠팡 API 키는 암호화(AES-256-GCM)해 서버에만 저장하고 화면·확장에는 다시 표시하지 않습니다. 회원가입·로그인은 없습니다. 서버에는 그 밖에 크롬 설치 구분용 식별자 해시, 이용권 상태, 줍은 상품 정보(쿠팡 상품 번호·제목·이미지 주소·가격·링크)와 결제 신청 정보(이메일·입금자명)만 저장합니다. 확장은 쿠팡 상품 페이지에서 사용자가 줍기 버튼을 눌렀을 때만 페이지 정보를 읽어 서버로 보내며, 다른 사이트의 데이터에는 접근하지 않습니다.

1. 서버에 저장·처리하는 정보

본 서비스는 사용자의 이름, 전화번호, 위치, 연락처, 사진 등 민감·신원 정보와 하드웨어 고유정보를 수집하지 않습니다. 쿠팡 파트너스 계정의 수익·리포트에는 접근하지 않습니다.

2. 크롬 확장이 접근하는 정보

  • 확장은 www.coupang.com 상품 페이지에서만 동작하며, 사용자가 줍기 버튼을 눌렀을 때 그 페이지의 제목·이미지 주소·가격·주소를 읽어 노마랩 서버로 보냅니다. 방문 기록이나 다른 사이트의 내용은 읽지 않습니다.
  • 확장이 쓰는 권한은 쿠팡 도메인 접근, 저장소(storage), 클립보드 쓰기(clipboardWrite), 현재 탭(activeTab)뿐입니다.
  • 확장은 로그인 세션과 설치 식별자를 브라우저의 확장 저장소(storage.local)에만 보관합니다. 브라우저 동기화(sync)에는 저장하지 않습니다.
  • 파트너스 링크는 사용자가 버튼을 눌렀을 때만 만들어집니다. 다른 사이트의 링크를 파트너스 링크로 바꾸는 동작은 하지 않습니다.

3. 외부 서비스로의 요청

  • 쿠팡 파트너스 Open API: 노마랩 서버가 사용자 본인의 API 키로 링크 생성(딥링크) 요청을 보냅니다. 요청에는 상품 주소와 사용자가 정한 subId만 포함됩니다. — 쿠팡 파트너스

5. 결제·이용권에 관하여

유료 이용권은 무통장 입금 방식으로 신청하고, 입금 확인 후 신청한 기간만큼 부여됩니다. 자동결제는 없습니다. 이용권이 만료되면 링크 생성만 멈추고 줍은 목록의 조회·복사·삭제는 계속 이용할 수 있습니다. 환불 규정 등 거래 조건은 구매 페이지 및 이용약관에 별도로 고지됩니다.

6. 데이터 보관 및 삭제

쿠팡 API 키는 사용자가 확장 설정에서 언제든 삭제할 수 있으며, 삭제 즉시 서버에서 파기됩니다. 줍은 상품은 목록에서 개별 삭제할 수 있습니다. 이 크롬에 연결된 전체 데이터의 삭제를 원하시면 아래 문의 이메일로 요청해 주세요. 요청 시 관련 법령상 보존 의무가 있는 항목(결제 신청 기록 등)을 제외하고 지체 없이 삭제합니다. 이용권이 6개월 이상 만료된 계정의 줍은 상품 정보는 사전 안내 후 정리될 수 있습니다.

7. 안전성 확보 조치

  • 쿠팡 API 키는 AES-256-GCM 방식으로 암호화해 저장하며, 복호화 키는 서버 환경변수에만 둡니다.
  • 데이터베이스는 행 단위 접근 제어(RLS)로 본인 데이터만 조회할 수 있게 제한하고, API 키 표는 서버만 접근합니다.
  • 확장과 서버 사이 통신은 HTTPS로만 이루어집니다.
